# Ejercicio: Sobrecarga de métodos

## 📌 Descripción

Este ejercicio consiste en desarrollar una clase llamada `Impresora` utilizando el concepto de **sobrecarga de métodos** en Java.

La clase contiene cuatro métodos llamados `imprimir`, cada uno con diferentes parámetros. Aunque todos tienen el mismo nombre, Java permite distinguirlos según el número y el tipo de parámetros que reciben.

Además, se comprueba que no es posible diferenciar dos métodos únicamente por su tipo de retorno.

## ✅ Conclusión

Con este ejercicio se aprende a utilizar la sobrecarga de métodos en Java, permitiendo crear varios métodos con el mismo nombre siempre que tengan diferentes listas de parámetros.

También se comprende que Java distingue los métodos por su nombre y sus parámetros, pero no por el tipo de retorno.

La sobrecarga permite reutilizar nombres de métodos y organizar mejor el código, facilitando su lectura y utilización.
